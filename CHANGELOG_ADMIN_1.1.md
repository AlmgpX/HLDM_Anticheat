# HLDM Anticheat 1.1 admin tools

- local per-admin hull and body-zone overlay;
- through-wall diagnostic mode;
- aimed-player HUD with userid, SteamID, model, health, armor, and hitgroup;
- aimed-player status/trap/untrap commands;
- F6-F12 local bind config;
- optional SteamID admin registration in users.ini;
- complete setup wrapper for an existing Steam Half-Life folder.
