# Roadmap

## 1.0 — готовый автоматический сервер

Выполнено:

- укреплённый trap core;
- ручная и офлайн-маркировка;
- nVault-персистентность;
- admin/self/bot safety;
- damage/input effects и false recovery;
- model guard и auto-trap custom-моделей;
- detector snap-fire, instant reaction, rapid switch и invalid angles;
- score с затуханием, multi-signal threshold, minimum events и cooldown;
- observe-only и automatic modes;
- детекторные логи и admin-команды;
- установка в существующий Half-Life;
- чистая установка HLDS через SteamCMD;
- Metamod/AMXX setup, launcher и Firewall;
- warning-free CI package.

## 1.1 — калибровка на живых матчах

- собрать распределение score честных игроков разного уровня;
- вынести рекомендованные профили `strict`, `balanced`, `tournament`;
- добавить статистику percentiles в admin-console;
- добавить map-specific исключения для необычных sightline;
- записывать версию конфига рядом с detector event;
- нагрузочный тест на 32 клиента.

## 1.2 — расширенная телеметрия

- устойчивость повторяемой угловой скорости;
- корреляция fire edge и попадания;
- серия идентичных snap-duration;
- затухание не только score, но и старых evidence-категорий;
- экспорт событий в CSV/JSON без внешнего сервиса;
- replayable тестовые последовательности `usercmd`.

## 1.3 — wallhack-oriented наблюдение

Без притворства, будто сервер читает мысли:

- pre-aim по невидимой цели;
- удержание угла на цели за стеной;
- повторяемое сопровождение нескольких невидимых игроков;
- обязательное накопление длительной истории;
- только observe-only до проверки false positives.

## 1.4 — персональные приманки

Экспериментальная ветка:

- decoy-сущности только в пакете выбранного клиента;
- `FM_AddToFullPack`;
- отсутствие влияния на остальных;
- лимиты сущностей и сетевой нагрузки;
- отключение одним cvar при несовместимости.

## Не входит в core

Fake-client «палач» или сторонняя бот-система не включаются в базовый release. Это отдельный слой с собственной навигацией, совместимостью и риском превратить античит в цирк, который сам занимает слот и застревает в двери.
