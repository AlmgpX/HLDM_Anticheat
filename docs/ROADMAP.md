# Roadmap

## 0.2 — укреплённый core

- правильный AutoExecConfig path;
- ручная и офлайн-маркировка;
- админская иммунность и emergency stop;
- персистентность;
- урон и usercmd-сбои;
- false recovery;
- model guard и auto-trap;
- CI package.

## 0.3 — телеметрия без наказания

- угловая скорость прицела;
- величина поворота за один usercmd;
- выстрел в кадре snap-поворота;
- повторяемость одинаковых snap-паттернов;
- время между появлением видимой цели и атакой;
- смена целей за короткое окно;
- накопительный score с затуханием;
- команды просмотра только для администратора.

По умолчанию detector работает в observe-only и никого не помечает.

## 0.4 — контролируемое автоматическое применение

- пороги по нескольким независимым сигналам;
- отдельный `auto_apply` cvar;
- cooldown и защита от единичных фликов;
- исключения для ботов, администраторов и spectator;
- replayable тестовые последовательности usercmd.

## 0.5 — персональные приманки

Экспериментальная ветка:

- decoy-сущности только в пакете выбранного клиента;
- `FM_AddToFullPack`;
- отсутствие влияния на остальных;
- лимиты сущностей и сетевой нагрузки;
- отключение одним cvar при несовместимости.

## 0.6 — палач

Отдельный fake client или бот. Не смешивать с core до проверки конкретной бот-системы, навигации и совместимости с HLDM.
