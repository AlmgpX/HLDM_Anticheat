# HLDM Leader Curse 1.0

Плагин сравнивает фраги каждого игрока со средним количеством фрагов всех остальных подключённых игроков. Администраторы по умолчанию исключены.

## Сообщение тестового сервера

При входе и затем каждые 90 секунд сервер сообщает:

```text
[TEST SERVER] ZOV ZIP ZONA is experimental. A vindictive anti-cheat is being developed here.
[ZONA] Suspicious dominance may mutate ammunition, footsteps, weapons and dignity.
```

## Лидерство +5

При преимуществе минимум в пять убийств над средним результатом остальных:

- каждое подходящее ammo-сущность имеет 28% шанс исчезнуть при подборе;
- вместо неё игрок получает арбалет и три порции `ammo_crossbow`;
- сетевые арбалетные болты Half-Life являются взрывными;
- игрок получает HUD-подколку о превращении патронов.

## Лидерство +10

Штатные звуки шагов заменяются случайно на:

- крики учёного;
- звуки bullsquid, похожие на свиные.

Это происходит только для игрока, чей счёт превышает средний минимум на десять.

## Лидерство +15

Попытка стрелять из Gauss или Egon немедленно:

- создаёт визуальный взрыв;
- убивает владельца оружия;
- выводит публичную и личную подколку.

На каждом новом респавне правило продолжает действовать, пока преимущество остаётся не меньше пятнадцати.

## HUD-подколки

Игроки в активном tier получают случайную фразу каждые 12–20 секунд. При первом переходе порога сервер также публикует короткое сообщение для всех.

## Проверка

```text
amx_leadercurse_status
amx_leadercurse_notice
```

## Снарки

В конфигурации Weapon Lab лимит снарков на владельца повышен с 6 до 30:

```text
hldm_weaponlab_snark_max "30"
```
