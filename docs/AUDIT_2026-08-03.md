# Аудит 2026-08-03

## Критические находки исходного 0.1.0

1. `AutoExecConfig(true, "hldm_trap")` загружает `addons/amxmodx/configs/plugins/hldm_trap.cfg`, но установщик копировал файл в `configs/hldm_trap.cfg`. Настройки из репозитория фактически могли не выполняться.
2. `cmd_target(..., CMDTARGET_ALLOW_SELF)` не включает `CMDTARGET_OBEY_IMMUNITY`; админская иммунность отсутствовала.
3. Self-target и боты не были защищены.
4. В README заявлялась CI-компиляция, но на проверенном commit не было опубликованного статуса, поэтому компиляция не считалась подтверждённой.
5. Персистентность не покрывала ручную маркировку, сделанную до получения окончательного SteamID.
6. Удалитель переписывал `plugins.ini` в ASCII.

## Что исправляет 0.2.0

- корректный путь AutoExecConfig;
- отдельные safety-cvar;
- отложенное восстановление nVault;
- офлайн-команды по SteamID;
- emergency stop;
- auto-trap за custom-модель;
- независимый тик фаз;
- более строгий contract check;
- CI-пакет с правильным деревом AMXX.

## Остаточный риск

Без живого HLDS smoke test нельзя честно утверждать, что конкретная комбинация HLDS/ReHLDS, Metamod и AMXX не имеет мод-специфических особенностей. CI доказывает компиляцию, но не сетевое поведение движка.
