# План проверки

## Статическая проверка

```text
python tools/check_contract.py
```

Проверяется:

- наличие ключевых файлов;
- отсутствие клиентских команд;
- наличие всех обязательных admin-команд;
- наличие ранних выходов для обычных игроков;
- соответствие основных cvar исходнику и конфигу.

## Компиляция

CI скачивает официальный AMX Mod X 1.10 build 5479 и компилирует `.sma`. Артефакт workflow содержит `hldm_trap.amxx`.

## Серверный smoke test

1. Запустить чистый HLDM с двумя клиентами.
2. Убедиться, что до `amx_trap` урон и управление одинаковы.
3. Пометить только клиента B.
4. Проверить, что клиент A не затронут.
5. Проверить уменьшение урона B и усиление получаемого B урона.
6. Дождаться recovery-фазы и убедиться, что эффекты временно исчезают.
7. Переподключить B и проверить восстановление ловушки по SteamID.
8. Выполнить `amx_untrap` и снова проверить ванильное поведение.

## Model guard

1. Установить клиенту `model cdc` или другое нестандартное имя.
2. Проверить в `user <userid>`, что сервер заменил модель на `gordon`.
3. Проверить, что стандартные модели не заменяются.
