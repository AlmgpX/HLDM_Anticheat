# Архитектура

## Инвариант обычного сервера

Пока `g_trapped[id] == false`, обработчики урона и пользовательских команд немедленно возвращают `HAM_IGNORED`/`FMRES_IGNORED`. Поэтому обычный игрок не получает изменения физики, оружия или урона.

Исключение — включённый по умолчанию model guard. Он заменяет только нестандартное имя player-модели на одну из штатных моделей HLDM. Его можно отключить через `hldm_trap_force_standard_models 0`.

## Состояния цели

```text
SOFT -> RECOVERY -> HARD -> RECOVERY -> HARD ...
```

- `SOFT`: половинная интенсивность.
- `RECOVERY`: эффекты временно выключены.
- `HARD`: полная интенсивность.

Переходы зависят от серверного `get_gametime()`, поэтому переподключение не переносит текущую фазу, но при включённой персистентности снова активирует ловушку по SteamID.

## Серверные перехваты

- `Ham_TakeDamage`: масштабирование исходящего и входящего урона.
- `FM_CmdStart`: изменение только текущей команды помеченного клиента.
- `client_infochanged`: фильтрация нестандартной player-модели.
- `nVault`: постоянный список помеченных SteamID.

## Запрещённые подходы

В репозитории намеренно запрещены `client_cmd`, `engclient_cmd` и аналоги, которые отправляют команды на клиент. Плагин не должен менять конфиги, бинды, файлы или настройки игрока.
