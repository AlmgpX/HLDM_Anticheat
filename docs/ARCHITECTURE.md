# Архитектура

## Инвариант обычного сервера

Пока `g_trapped[id] == false`, обработчики урона и пользовательских команд немедленно возвращают `HAM_IGNORED` / `FMRES_IGNORED`. Обычный игрок не получает изменения физики, оружия или урона.

Исключение: глобальный model guard. Он заменяет нестандартное имя player-модели на штатную модель HLDM. Общий `hldm_trap_enabled 0` отключает и ловушку, и model guard.

## Жизненный цикл клиента

```text
client_connect -> reset slot
client_authorized -> cache SteamID, schedule persistence restore
client_putinserver -> mark in-server, schedule model check and restore
client_disconnected -> cancel tasks and reset slot
```

Отложенное восстановление nVault нужно потому, что `client_authorized` может прийти до или после `client_putinserver`, а админские флаги должны успеть загрузиться до проверки иммунитета.

## Состояния цели

```text
SOFT -> RECOVERY -> HARD -> RECOVERY -> HARD ...
```

- `SOFT`: половинная интенсивность.
- `RECOVERY`: эффекты временно выключены.
- `HARD`: полная интенсивность.

Фазы обновляются отдельным секундным тиком и дополнительно проверяются непосредственно перед обработкой урона/ввода.

## Серверные перехваты

- `Ham_TakeDamage`: масштабирование исходящего и входящего урона.
- `FM_CmdStart`: изменение только текущей команды помеченного клиента.
- `client_infochanged`: фильтрация нестандартной player-модели.
- `nVault`: постоянный список валидных SteamID/ValveID.

## Командная безопасность

- команды требуют `ADMIN_RCON`;
- администраторы защищены по умолчанию;
- self-target и боты запрещены по умолчанию;
- `amx_trap_stop` немедленно выключает эффекты без удаления списка целей;
- офлайн-команды принимают только постоянные `STEAM_...` / `VALVE_...` идентификаторы.

## Запрещённые подходы

Проект не использует `client_cmd`, `engclient_cmd`, `amxclient_cmd`, клиентские бинды, изменение файлов, краши, кик или бан. Это серверная механика матча, а не удалённое ковыряние чужой машины.

## Следующий слой

Детектор не должен быть впаян в core хаотическим комом. Он сначала собирает телеметрию в режиме наблюдения, затем выдаёт score, и только отдельный cvar разрешает автоматическое применение ловушки.
