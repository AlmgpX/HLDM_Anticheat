# Архитектура HLDM Anticheat

## Два независимых слоя

```text
hldm_detector.amxx -> server command amx_trap #userid -> hldm_trap.amxx
```

Детектор только наблюдает, считает score, пишет лог и при достижении порога просит ловушку пометить конкретный `userid`. Ловушка не знает, почему цель была выбрана: вручную, за custom-модель или детектором. Такое разделение позволяет выключить автоматизацию, не ломая ручное администрирование.

## Инвариант обычного игрока

Пока `g_trapped[id] == false`, обработчики ловушки немедленно возвращают `HAM_IGNORED` / `FMRES_IGNORED`. У обычного игрока не меняются ввод, урон и физика.

Исключение: глобальный model guard. Он заменяет нестандартное имя player-модели на штатное. Общий `hldm_trap_enabled 0` отключает и эффекты цели, и model guard.

Детектор читает `usercmd` и выполняет ограниченный visibility scan, но не изменяет команду обычного клиента.

## Жизненный цикл ловушки

```text
client_connect -> reset slot
client_authorized -> cache SteamID, schedule persistence restore
client_putinserver -> mark in-server, schedule model check and restore
client_disconnected -> cancel tasks and reset slot
```

Отложенное восстановление nVault нужно потому, что `client_authorized` может прийти до или после `client_putinserver`, а админские флаги должны успеть загрузиться до проверки иммунитета.

## Состояния цели

```text
SOFT -> RECOVERY -> HARD -> RECOVERY -> HARD ...
```

- `SOFT`: половинная интенсивность.
- `RECOVERY`: эффекты временно выключены.
- `HARD`: полная интенсивность.

Фазы обновляются отдельным секундным тиком и проверяются перед обработкой урона и ввода.

## Перехваты ловушки

- `Ham_TakeDamage`: масштабирование исходящего и входящего урона.
- `FM_CmdStart`: изменение только текущей команды помеченного клиента.
- `client_infochanged`: фильтрация нестандартной player-модели.
- `nVault`: постоянный список валидных SteamID/ValveID.

## Перехваты детектора

- `FM_CmdStart`: чтение `UC_ViewAngles`, кнопок и временных интервалов.
- `EngFunc_TraceLine`: проверка фактической цели выстрела и прямой видимости.
- секундный task: линейное затухание score.
- `log_to_file`: независимый журнал сигналов.

Visibility scan ограничен cvar `hldm_ac_visibility_scan_interval` и по умолчанию выполняется не чаще 20 раз в секунду на живого, не освобождённого игрока.

## Модель score

Сигнал добавляет очки и отмечает категорию:

```text
snap-fire
instant-reaction
rapid-target-switch
invalid-angles
```

Автоматическое применение требует одновременно:

```text
score >= threshold
число категорий >= minimum_categories
число событий >= minimum_events
истёк cooldown
```

Это снижает вероятность реакции на единичный честный флик. Score постепенно уменьшается, но счётчики событий и категорий сохраняются до переподключения или `amx_ac_reset`.

## Интеграция

Детектор вызывает серверную команду:

```text
amx_trap #<userid>
```

Используется `userid`, а не слот. При повторном использовании слота новым клиентом команда не должна попасть в старую цель.

`hldm_trap.amxx` обязан стоять выше `hldm_detector.amxx` в `plugins.ini`.

## Идентификаторы

- постоянные SteamID/ValveID сохраняются в nVault;
- `STEAM_ID_LAN`, `VALVE_ID_LAN`, pending, bot и HLTV не сохраняются;
- LAN-клиент может быть целью в текущем соединении;
- проект не подменяет SteamID и не хранит автоматическое наказание по одному IP.

## Командная безопасность

- команды требуют `ADMIN_RCON`;
- администраторы исключены из автоматического детектора по умолчанию;
- self-target и боты защищены в ловушке;
- `amx_trap_stop` немедленно выключает эффекты без удаления списка целей;
- `amx_ac_mode 1` оставляет только наблюдение и лог.

## Запрещённые подходы

Проект не использует `client_cmd`, `engclient_cmd`, `amxclient_cmd`, клиентские бинды, изменение файлов, краши, кик или бан. Статический contract check блокирует появление этих вызовов в `src/*.sma`.

## Развёртывание

Setup-скрипт формирует цепочку:

```text
liblist.gam -> Metamod-P -> AMX Mod X -> plugins.ini -> trap -> detector
```

Скрипт делает резервные копии изменяемых конфигураций, но не удаляет чужие плагины и не сносит существующий AMX Mod X. Чудеса осторожности иногда случаются даже в PowerShell.
