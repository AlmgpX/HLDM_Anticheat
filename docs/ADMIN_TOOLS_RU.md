# Локальные инструменты администратора

`hldm_admin_tools.amxx` рисует диагностический оверлей только тому администратору, который включил его командой. Другие игроки линии не получают. Сервер не меняет клиентские бинды удалённо и не отправляет клиентские консольные команды.

## Что показывает оверлей

- внешний серверный collision hull игрока;
- три вложенные зоны: голова, корпус и нижняя часть тела;
- отдельный цвет игрока под прицелом;
- пурпурный цвет нестандартной player-модели;
- HUD под прицелом: userid, имя, SteamID, модель, здоровье, броня и hitgroup.

Важно: GoldSrc/AMX Mod X не отдаёт плагину полный массив модельных Studio hitbox из MDL. Поэтому это серверные габариты и диагностические зоны, а не послойный экспорт всех модельных хитбоксов. Для поиска однопиксельных моделей, стрельбы через стены и проверки попаданий этого достаточно; выдавать приближение за точную геометрию было бы уже традиционной человеческой магией маркетинга.

## Установка в существующую Half-Life

Для пути:

```text
E:\SteamLibrary\steamapps\common\Half-Life
```

запусти PowerShell в распакованном пакете:

```powershell
Set-ExecutionPolicy -Scope Process Bypass

.\deploy\install_admin_tools_windows.ps1 `
  -HalfLifeRoot "E:\SteamLibrary\steamapps\common\Half-Life" `
  -AdminSteamId "STEAM_0:1:12345678"
```

Свой SteamID можно увидеть командой `status` после подключения к серверу.

Скрипт:

- устанавливает `hldm_admin_tools.amxx`;
- устанавливает `configs/plugins/hldm_admin_tools.cfg`;
- добавляет плагин в `plugins.ini`;
- при указанном SteamID добавляет локального администратора в `users.ini`;
- создаёт `valve/hldm_admin.cfg`;
- добавляет `exec hldm_admin.cfg` в `valve/userconfig.cfg`.

После установки смени карту или перезапусти HLDS.

## Бинды

```text
F6   включить или выключить ESP
F7   переключить режим: hull / зоны / оба
F8   информация об игроке под прицелом
F9   включить ловушку игроку под прицелом
F10  выключить ловушку игроку под прицелом
F11  список detector-score
F12  список активных ловушек
```

Если конфиг не выполнился автоматически:

```text
exec hldm_admin.cfg
```

Показать бинды в консоли:

```text
amx_ac_binds
```

## Команды

```text
amx_ac_esp
amx_ac_esp 0
amx_ac_esp 1

amx_ac_esp_mode
amx_ac_esp_mode 1
amx_ac_esp_mode 2
amx_ac_esp_mode 3

amx_ac_aim status
amx_ac_aim trap
amx_ac_aim untrap
```

## Цвета

- зелёный: штатная модель;
- красный: игрок находится под прицелом администратора;
- пурпурный: нестандартная player-модель;
- красно-оранжевый внутренний box: верхняя зона;
- синий внутренний box: нижняя зона.

## Настройка нагрузки

Конфиг:

```text
valve\addons\amxmodx\configs\plugins\hldm_admin_tools.cfg
```

Основные значения:

```cfg
hldm_admin_through_walls "1"
hldm_admin_max_distance "4096.0"
hldm_admin_line_life "4"
hldm_admin_line_width "1"
```

На сервере с большим числом игроков уменьши `hldm_admin_max_distance` или используй режим 1. Оверлей состоит из временных сетевых beam-сообщений и отправляется только включившему его администратору.
