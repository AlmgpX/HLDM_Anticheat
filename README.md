# HLDM Trap

Серверный AMX Mod X-плагин для обычного Half-Life Deathmatch. По умолчанию матч остаётся ванильным. Администратор вручную помечает конкретный клиент, после чего сервер применяет к нему только серверные эффекты: ослабляет исходящий урон, усиливает входящий, иногда съедает команды прыжка/атаки, кратко переворачивает стрейф и чередует наказание с ложным восстановлением.

Плагин не выполняет команды на клиенте, не меняет его файлы, не вызывает краши и не лезет за пределы игрового соединения. То есть это ловушка сервера, а не унылый slowhack из 2007 года.

## Уже реализовано

- `amx_trap <name|#userid|SteamID>`
- `amx_untrap <name|#userid|SteamID>`
- `amx_trap_list`
- сохранение помеченных SteamID через nVault;
- серверное изменение урона через Ham Sandwich;
- изменение текущего `usercmd` через Fakemeta;
- чередование punishment/recovery;
- персональный HUD;
- запрет нестандартных player-моделей с заменой на Gordon;
- GitHub Actions-компиляция под AMX Mod X 1.10 build 5479;
- проверка репозитория на случайное добавление клиентских команд.

## Требования

- обычный HLDS или ReHLDS с модом `valve`;
- Metamod;
- AMX Mod X 1.9+; целевая CI-версия: 1.10.0 build 5479;
- модули `fakemeta`, `hamsandwich`, `nvault`.

## Быстрый запуск

1. Скомпилировать `src/hldm_trap.sma`.
2. Положить `hldm_trap.amxx` в `valve/addons/amxmodx/plugins/`.
3. Добавить `hldm_trap.amxx` в `valve/addons/amxmodx/configs/plugins.ini`.
4. Скопировать `configs/hldm_trap.cfg` в `valve/addons/amxmodx/configs/`.
5. Перезапустить сервер или сменить карту.
6. Проверить `amxx plugins` и `amxx modules`.

Подробности: `docs/INSTALL_RU.md`.

## Администрирование

Команды требуют флаг `l` (`ADMIN_RCON`). Рекомендуемый способ выбирать цель:

```text
status
amx_trap #17
amx_trap_list
amx_untrap #17
```

`#17` здесь является `userid`, а не номером клиентского слота.

## Принцип разработки

В `main` попадает только то, что компилируется. Экспериментальные вещи вроде персональных decoy-сущностей через `FM_AddToFullPack`, fake-client-палача и автоматического скоринга должны идти отдельными ветками и PR. Человечество уже достаточно раз отлаживало продакшен непосредственно на живых пользователях.
